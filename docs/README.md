# 🌐 Temp Mail Pro — GitHub Pages Deployment Guide

Temp Mail Pro website is **100% ready for instant publishing on GitHub Pages**! It runs completely client-side in the browser with direct GuerrillaMail CORS APIs, live OTP detection, 30+ domains, auto-refresh polling, multi-language switching (8 languages), QR codes, panic shredder, and offline vault storage.

---

## 🚀 How to Publish on GitHub Pages (কিভাবে GitHub Pages-এ চালু করবেন)

### অপশন ১: সহজ এবং সরাসরি (Settings থেকে ৩ ক্লিকে চালু করুন)

1. আপনার GitHub রিপোজিটরিতে যান (`https://github.com/HANTER-XD-OFFICIAL/TEMP_MAIL_PRO`)
2. উপরের মেনু থেকে **Settings** ট্যাবে ক্লিক করুন
3. বাম পাশের সাইডবার থেকে **Pages** অপশনে ক্লিক করুন
4. **Build and deployment** সেকশনে:
   - **Source**: `Deploy from a branch` সিলেক্ট করুন
   - **Branch**: `main` সিলেক্ট করুন
   - **Folder**: `/docs` সিলেক্ট করুন
5. **Save** বাটনে ক্লিক করুন!

🎉 **ব্যাস! ১ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে:**
👉 `https://hanter-xd-official.github.io/TEMP_MAIL_PRO/`

---

### অপশন ২: GitHub Actions (স্বয়ংক্রিয় ডিপ্লয়মেন্ট)
আমরা রিপোজিটরির `.github/workflows/deploy-pages.yml` ফাইলে একটি অটোমেশন সেটআপ করে দিয়েছি। আপনি যখনই কোড পুশ করবেন, GitHub Actions স্বয়ংক্রিয়ভাবে ওয়েবসাইটটি GitHub Pages-এ পাবলিশ করে দিবে।

## 🌟 GitHub Pages ফিচারের সুবিধা (Features Included)

- ⚡ **১০০% সার্ভারলেস এবং ফ্রি**: কোনো Node.js বা ক্লাউড সার্ভারের খরচ ছাড়া আজীবন ফ্রিতে চলবে।
- 📧 **সরাসরি ব্রাউজার API**: GuerrillaMail CORS API-এর মাধ্যমে ব্রাউজার থেকেই মেইল তৈরি এবং ইনবক্স রিফ্রেশ হয়।
- 🔑 **রিয়েল-টাইম OTP ডিটেকশন**: Facebook, Google, Telegram, WhatsApp সহ সব প্ল্যাটফর্মের OTP কোড স্বয়ংক্রিয়ভাবে আলাদা করে গোল্ডেন ব্যাজে দেখায়।
- 🌐 **৩০+ ডোমেইন হাব**: sharklasers.com, guerrillamail.com, spam4.me ইত্যাদি থেকে ইনস্ট্যান্ট কাস্টম ইউজারনেম তৈরি।
- ✈️ **ঐচ্ছিক টেলিগ্রাম ও রেন্ডার ব্যাকএন্ড**: সেটিংস থেকে আপনার রেন্ডার ব্যাকএন্ড URL দিলে টেলিগ্রাম বট ফরোয়ার্ডিংও কাজ করবে।
- 📱 **সম্পূর্ণ রেসপন্সিভ ডিজাইন**: মোবাইল, ট্যাবলেট এবং কম্পিউটারে অ্যান্ড্রয়েড অ্যাপের মতো স্মুথ মেটেরিয়াল ডিজাইন ৩ ইউজার ইন্টারফেস।
